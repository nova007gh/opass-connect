# OPASS CONNECT feature map

## Membership & identity
- Registration/login
- Alumni verification queue
- Graduation year, house, class, former position, profession/location
- Searchable member directory
- Role-based access: member, year admin, moderator, admin, super admin

## Community
- Year groups and leadership
- Member directory and classmate search
- Chat rooms and message history
- OPASS-wide Assembly Hall model

## Meetings and media
- Scheduled interactive meetings
- Webinar mode
- Broadcast mode for very large audiences
- LiveKit room-token backend
- Event stream URL support

## Finance
- Annual dues/payment purposes
- Paystack initialization and server-side transaction verification
- Project fundraising and contribution tracking
- Payment ledger model

## Projects
- Alumni/year-group projects
- Funding goal and raised amount
- Project lifecycle status

## Elections
- Election scheduling
- Candidate registration by position
- One-member-one-vote per position enforced by database uniqueness
- Results visibility controls

## Alumni businesses
- Business profiles
- Verification state
- Advertising requests
- Placement, duration, audience, creative and quote
- Admin approval
